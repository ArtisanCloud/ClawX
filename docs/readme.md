# ClawX

## 第一阶段需求说明文档（V1）

---

# 1. 项目背景

ClawX 是一个面向专业开发者的多渠道 AI 开发网关系统。

它的目标是：

* 远程控制主流 AI 开发 CLI（如 Codex）
* 通过主流聊天渠道进行开发协作
* 提供统一的会话管理与流式返回机制
* 为未来接入 PowerX Agent Channel 做基础准备

第一阶段专注：

> “远程控制 Codex CLI”

---

# 2. 第一阶段核心目标

第一阶段的目标是：

* 让开发者可以在聊天工具中远程驱动 Codex CLI
* 支持基本的会话管理
* 支持流式或分段返回
* 支持多会话隔离
* 支持在远程服务器运行

---

# 3. 功能范围

## 3.1 CLI 驱动能力

### 必须支持

* 启动 Codex CLI
* 执行 `codex exec`
* 支持 `resume` 指定会话
* 支持指定工作目录
* 支持超时控制
* 支持取消当前执行

### 会话映射

* 每个聊天会话映射一个 Codex session
* 群聊 thread 映射独立 session
* 私聊映射独立 session
* 支持列出已有 session
* 支持切换 session

---

## 3.2 渠道接入能力

第一阶段支持：

* Discord Bot
* Telegram Bot

### 必须支持

* 私聊消息
* 群聊消息
* @bot 识别
* Thread 识别
* 基础指令（如 /new /list /resume）

---

## 3.3 消息处理能力

### 必须支持

* 消息转发到 CLI
* CLI 输出返回聊天渠道
* 长消息自动分段
* 支持代码块格式
* 支持基础 Markdown

---

## 3.4 流式能力

第一阶段可以实现：

* 分段输出（模拟流式）
* 或真正流式（若 CLI 支持）

必须保证：

* 执行中有“处理中”提示
* 输出按顺序返回
* 错误可回显

---

## 3.5 会话管理

必须支持：

* conversation_id 生成规则
* channel + thread 唯一键
* 多用户隔离
* 同一会话互斥执行
* 执行锁机制

---

## 3.6 基础系统能力

* 本地部署
* Linux 服务器运行
* 配置文件支持
* 日志输出
* 基础错误处理

---

# 4. 不在第一阶段范围内

以下功能明确不做：

* 多模型调度
* Claude CLI 支持
* Cursor 支持
* 插件系统
* RAG
* Tool Skill 框架
* 多租户
* 权限系统
* 审计系统
* Web 控制台
* 与 PowerX 集成

---

# 5. 系统行为定义

## 5.1 聊天行为

### 私聊

* 默认创建新 session
* 或自动恢复最近 session

### 群聊

* 仅在 @bot 时触发
* 每个 thread 独立 session
* 非 thread 群聊可选是否支持

---

## 5.2 执行行为

当用户发送：

> @bot 修复这个函数

系统行为：

1. 锁定当前会话
2. 调用 Codex CLI
3. 收集输出
4. 分段发送
5. 释放锁

---

## 5.3 异常行为

必须支持：

* CLI 失败回显
* 超时回显
* 并发冲突提示
* 取消执行提示

---

# 6. 性能与限制

第一阶段不追求高并发。

目标指标：

* 支持 5-20 并发会话
* 单次执行最长 10 分钟
* 支持长文本输出

---

# 7. 目标用户

第一阶段目标用户：

* 专业开发者
* 远程开发团队
* 使用 Discord / Telegram 协作的技术团队

---

# 8. 成功标准

第一阶段成功的定义是：

* 能在 Discord 中远程驱动 Codex
* 能正确维护会话
* 能处理长输出
* 能在服务器稳定运行
* 无严重崩溃

---

# 9. 产品定位总结

ClawX 第一阶段是：

> 一个远程 Codex CLI 控制网关
> 一个开发者远程 AI 协作工具
> 一个未来 PowerX Agent Channel 的前置实验平台

---

# 10. 一句话版本

ClawX 是一个将 AI 开发 CLI 与聊天渠道连接起来的远程控制中枢。
