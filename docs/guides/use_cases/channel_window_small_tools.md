# 渠道窗口小工具任务实操（多图拼长图）

## 1. 目标
在 Telegram / Discord / Feishu / WeCom 任一已接入渠道中，通过 ClawX 对服务器上的多张图片进行竖向拼接，生成一张长图。

## 2. 使用前准备
1. 渠道已接入并可正常对话。
2. Agent workspace 可用，且在允许目录内。
3. 输入图片已放入 workspace，例如：
   - `./tmp/images/01.jpg`
   - `./tmp/images/02.png`
4. 运行环境具备至少一种工具：
   - `magick`（ImageMagick）
   - 或 `python3 + Pillow`

## 3. 渠道窗口操作步骤
1. 在渠道里发 `/new` 新建会话。
2. 发送下面这段指令（可直接复制）：

```text
请在当前 workspace 执行图片拼接任务：
1) 先检查是否可用 magick；若不可用则使用 python3 + Pillow。
2) 读取 ./tmp/images 下所有 jpg/jpeg/png 文件，按文件名升序排序。
3) 将图片按竖向拼接，输出 ./tmp/output/long.png。
4) 输出执行日志、输出文件绝对路径、图片尺寸（宽x高）。
5) 若失败，给出可重试命令。
```

3. 收到完成信息后，核对输出路径。

## 4. 验证方式
1. 文件存在性：`./tmp/output/long.png` 存在。
2. 输出尺寸正确：宽度与目标规则一致，高度为输入图累计。
3. 渠道回复包含：
   - 最终文件路径
   - 执行方式（magick 或 python）
   - 失败时可重试命令

## 5. 常见失败与处理
### 5.1 找不到图片
- 现象：报错 `no such file or directory`。
- 处理：确认图片已在当前 agent 的 workspace 下，路径拼写正确。

### 5.2 `magick` 不可用
- 现象：报错 `command not found: magick`。
- 处理：让任务自动回退到 `python3 + Pillow`；或提前安装 ImageMagick。

### 5.3 Pillow 缺失
- 现象：报错 `No module named PIL`。
- 处理：安装依赖后重试（例如 `pip install pillow`）。

### 5.4 输出目录不存在
- 现象：报错写入失败。
- 处理：让任务先创建目录 `./tmp/output` 再写文件。

## 6. 能力边界（当前版本）
1. 渠道内附件“直接上传并处理”未形成统一流程。
2. 生成图片“直接回传为渠道图片消息”未统一支持。
3. 大文件异步处理、进度查询、任务队列尚未标准化。

## 7. 若要升级为“收图即回图”能力，建议补齐
1. 统一附件模型（下载 URL / MIME / 大小 / 来源渠道）。
2. 统一媒体网关（附件下载、产物上传、渠道回传）。
3. 统一产物存储（对象存储 + 短链或 media_id）。
4. 异步任务编排（任务 ID、进度、重试、取消）。
5. 文件安全策略（白名单、大小限制、隔离、配额、扫描）。
