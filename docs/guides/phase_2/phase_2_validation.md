# Phase 2 验证指南（占位）

## 目的

用于记录第二阶段“多窗口多会话”的人工验收与回归结果。

## 验收范围

- 多窗口独立会话不串线
- 同窗口会话恢复与切换
- 兼容路径（无显式 `window_id`）
- 控制命令窗口语义

## 前置条件

1. 当前分支：`002-multi-session`
2. 基础测试可运行：`go test ./...`
3. 已具备测试入口（Discord/Telegram 或统一路由测试桩）

## 最小验收步骤（草案）

1. 在窗口 A 创建或继续会话，记录 `session_id`。
2. 在窗口 B 创建或继续会话，确认与窗口 A 不同。
3. 在窗口 A 连续发送两条消息，确认仍命中窗口 A 当前会话。
4. 在窗口 A 执行 `/list`，确认当前会话标记正确。
5. 在窗口 A 执行 `/switch <session_id>`，确认后续输入进入目标会话。
6. 使用无显式 `window_id` 路径发送请求，确认兼容路径可用。
